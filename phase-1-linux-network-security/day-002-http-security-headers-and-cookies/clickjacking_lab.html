🕵️‍♂️ Day 002 Lab: Clickjacking (`X-Frame-Options`) စမ်းသပ်ချက်

Hacker တွေက သူတို့ရဲ့ အတုအယောင် Website ထဲမှာ မင်းရဲ့ Website (`https://vvip9.co`) ကို <iframe> နဲ့ အကြည်ရောင် (Invisible) ထည့်ပြီး User ကို မသိဘဲ ခလုတ်နှိပ်မိအောင် လှည့်စားတာကို Clickjacking လို့ ခေါ်ပါတယ်။

အောက်က အနီရောင် ဘောင်ထဲမှာ https://vvip9.co ပွင့်လာလား၊ ဒါမှမဟုတ် X-Frame-Options: SAMEORIGIN ကြောင့် Browser က ပိတ်ချလိုက်လား ကြည့်ပါ! 👇
