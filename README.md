## 🎯 Why This Repository Exists

ဒီ Repository ဟာ **Web Developer (PHP/Laravel, JavaScript/Vue/Inertia, MySQL/Redis)** နဲ့ **Linux Server Administrator (Ubuntu, Nginx, SSH, Docker, GitHub Actions)** အခြေခံရှိပြီးသား Developer တစ်ယောက်အနေနဲ့ **ရက် (၁၀၀) အတွင်း Cybersecurity (Offensive + Defensive) နဲ့ DevSecOps** ကို လက်တွေ့ကျကျ ကျွမ်းကျင်ပိုင်နိုင်အောင် လေ့ကျင့်မှတ်တမ်းတင်ထားတဲ့ **Hands-on Portfolio & Knowledge Sharing Hub** ဖြစ်ပါတယ်။

### 🏆 100 Days အပြီး ရရှိလာမည့် ရလဒ် (4 Core Outcomes)
1. **🔴 Offensive Security (Hacker Mindset):** Web Applications, REST APIs, Linux Servers နဲ့ Docker Containers တွေရဲ့ ဟာကွက် (OWASP Top 10, API Top 10, Misconfigurations) ကို ကိုယ်တိုင် ရှာဖွေစမ်းသပ်တတ်မည်။
2. **🔵 Defensive Engineering & DevSecOps:** Laravel Code, Nginx, Linux Firewall, Docker နဲ့ GitHub Actions CI/CD Pipeline တွေမှာ အဆိုပါ التိုက်ခိုက်မှုတွေကို အလိုအလျောက် ကာကွယ်ပိတ်ဆို့တတ်မည်။
3. **🎓 Industry Certifications & Verifiable Badges:** Phase အလိုက် **100% Free Official Certificates** (ISC2 CC, APIsec University, Fortinet FCF/FCA, Cisco NetAcad, Linux Foundation) နှင့် High-ROI Certifications (PortSwigger BSCP, CompTIA Security+) များ ရယူမည်။
4. **📢 Public Tech Creator & Remote Job Portfolio:** နေ့စဉ် လေ့လာသမျှကို **GitHub Portfolio**, **Blog/Medium/Dev.to Article**, နှင့် **YouTube/TikTok 60s Video Script** အဖြစ် ပြန်လည်မျှဝေသွားမည်။

## ⏱️ Daily 60-Minute Study Workflow

မနက်ဖြန်ရောက်တိုင်း *"ဒီနေ့ ဘာလုပ်ရမလဲ?"* လို့ စဉ်းစားစရာမလိုအောင် နေ့တိုင်း အောက်ပါ **၄ ဆင့်** အတိုင်း အတိအကျ သွားပါမယ်—

1. **🧠 00:00 – 00:15 (15 mins) | Story & Under the Hood**
   - [ROADMAP-100-DAYS.md](./ROADMAP-100-DAYS.md) က ဒီနေ့ကျတဲ့ Day ကို ဖတ်မယ်၊ AI နဲ့အတူ အဲ့ဒီ Attack က နောက်ကွယ်မှာ ဘယ်လို အလုပ်လုပ်လဲ မေးမြန်းဆွေးနွေးမယ်။
2. **🔴 00:15 – 00:30 (15 mins) | Red Team Attack Lab**
   - Local Docker Lab (`labs/docker-compose.yml`) သို့မဟုတ် PortSwigger / OverTheWire ပေါ်မှာ Hacker တစ်ယောက်လို ကိုယ်တိုင် ဖောက်ထွင်းစမ်းသပ်မယ်။
3. **🔵 00:30 – 00:45 (15 mins) | Blue Team / DevSecOps Fix**
   - အဲ့ဒီ ဟာကွက်ကို Laravel / Nginx / Linux / Docker မှာ ဘယ်လို ပိတ်မလဲ လက်တွေ့ Code/Config ရေးမယ်။
4. **📢 00:45 – 01:00 (15 mins) | Document, Cert Check & Share**
   - [templates/DAILY-NOTE-TEMPLATE.md](./templates/DAILY-NOTE-TEMPLATE.md) သုံးပြီး ဒီနေ့ Note ကို သိမ်းမယ်၊ Blog/Video Script ထုတ်မယ်၊ အောက်က Progress Table မှာ `[x]` ခြစ်မယ်!
